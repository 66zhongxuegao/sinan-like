01画像自测

先知道“差在哪”，再决定“练什么”

学员完成初始能力测评后，系统把答题结果转化为八维能力画像，并给出学习建议。训练不是从统一课表开始，而是从每个人当前的能力位置开始。

  • 八维能力基线测评覆盖八个能力维度，结果形成可解释的初始画像。
  • 建议落到行动系统给出学习建议，明确先补什么、怎么练。
  • 画像驱动难度后续学习与实战难度不是固定值，而是从画像出发。
02个性化学习

每个技能点，都有对应的学习材料

学员在学习地图中点击具体技能点，司南教学 Agent 会调度多 Agent 协同生成个性化资源。每份材料都不是孤立内容，而是挂接到知识点与实战记录上。

  • 地图式学习路径按技能点组织学习进度，点击即可进入当前训练主题。
  • 多 Agent 协同生成讲义、学习报告、实操指南按学情生成，而不是一套内容发给所有人。
  • 资源可以回溯每份资源对应知识点与实战记录，复习时能找到“为什么学”。
03动态做题

题目会跟着你的表现变难

做题过程中，系统实时观察学员表现并调整难度。连续答对会升档，失误或表现不稳定时会降档，让训练始终停在“有挑战但够得着”的位置。

  • 一到五级难度难度不是一套固定题库，而是动态变化的训练参数。
  • 答对升档、失误降档连续答对多题则提升难度，反之亦然。
  • 训练和实战共享画像做题表现持续进入学情画像，成为后续资源与实战难度的依据。
04接单与首呼

倒计时里抢单，通话里确认真实需求

系统根据学员当前能力画像确定实战难度并派发虚拟订单。抢单成功后进入订单管理，超时未抢则订单流走；随后通过首呼与虚拟客户确认基本信息，并把口语需求整理成结构化需求单。

  • 派单看画像综合实战难度由当前能力画像决定，不是随机发一张固定订单。
  • 抢单有真实后果倒计时内抢单进入管理；超时则被其他定制师接走，需要刷新重抢。
  • 首呼落到需求单确认称呼、客源地、人数等基本信息，并结构化整理客户需求。
05行前方案

从资源询价到合同交付，走完行前每一环

学员在资源大群向虚拟地接社、酒店、车队与票务询价，随后创建行程方案、根据客户反馈迭代、测算成本与利润、完成分项报价，最终提交合同、保险与出团通知书。

  • 多资源方询价房、车、票、导等资源在群聊里逐项确认，模拟真实履约链条。
  • 方案随反馈迭代客户提出修改或异议后，学员要调整方案并解释取舍理由。
  • 报价、合同、保险齐全从实际开销、利润到分项报价，再到合同、保险和出团通知书。
06行中应急

行中出事时，先做什么比做什么更重要

系统会随机生成车辆故障、酒店超售、票务变化等突发事件，并分发到对应虚拟工作群。学员需要按正确处理顺序介入：先安抚客户，再协调资源，最后解决问题。

  • 随机突发事件故障、超售、票务变化等场景进入真实工作群，不是看一道选择题。
  • 顺序本身会被评估先安抚、再协调、后解决；顺序错误或处理不当都会影响评分。
  • 结果进入应急维度沟通质量与解决方案共同进入“应急解决”能力评分。
07行后复盘

结算、评分、画像回写，闭环才真正完成

行程结束后，学员核对地接结算单与实际成本，处理赔偿与追偿，结账留档并计算实际利润。系统再对 61 个技能点逐项评分，把结果写回画像，决定下一单的难度与补强方向。

  • 结算经得起核对地接结算、实际成本、赔偿追偿与最终利润逐项核对并留档。
  • 每一分都有证据61 个技能点逐项评分，每个分数都带证据坐标。
  • 画像回写下一单评分结果写回画像，下一单的难度参数与待补强技能点随之调整。
