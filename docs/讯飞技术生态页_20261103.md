## 二、页面采用的官方事实

- 实时语音听写：官方页面说明支持 65 个语种、23 种方言和 1 个民族语言，实时返回结果。
- 语音分析大模型：官方页面说明其基于“异步转写 + 大模型分析”，面向录音质检、商机挖掘、满意度分析等场景；页面场景举例包含“识别通话中的投诉倾向和负面情绪”。
- 语音翻译：官方页面名称为“语音翻译”。
- 语音评测：官方页面说明提供中英文发音精准、多维评估，应用于中高考、四六级、普通话等考试场景。
- 在线语音合成：官方页面说明提供 100+ 发音人，支持多语种、多方言和中英混合。
- 星火大模型 Spark-X2.6：官方 API 页面描述为基于国产算力训练、采用 293B-A30B MoE 架构、上下文长度 1M。
- 讯飞开放平台：官方首页称其为“以语音交互为核心的人工智能开放平台”。
