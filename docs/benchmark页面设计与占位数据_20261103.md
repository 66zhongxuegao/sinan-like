# Benchmark 页面设计与占位数据

> 日期：2026-11-03  
> 对应页面：`output/slide-template/index.html` 第 07、08 页  
> 版式依据：严格参考去年获奖 PPT 的“定性分析 / 定量分析”两页，不采用柱状图、KPI 卡或消融看板。  
> 重要说明：以下数值、模型排名和勾叉结果全部为**虚构占位**。正式提交前必须用真实实验结果整体替换。

## 1. 版式原则

两页都只保留四个层级：

1. 左上标题：`定性分析` / `定量分析`
2. 标题后的收益判断：`全链路岗位能力覆盖` / `三项硬指标全面达标`
3. 一张占满主体区域的排行榜或能力矩阵
4. 底部一条深蓝结论横幅

不放：样本量、置信区间、指标定义、方法说明、图例、消融实验、额外 KPI、脚注。

## 2. 定性分析页

标题：**定性分析 >> 全链路岗位能力覆盖**

矩阵规模：5 行模型 × 14 列能力。

模型：

- GPT-6 Astra（2026-09 前沿旗舰外部基线）
- Qwen3.8-Max + RAG（国产前沿模型 + 检索增强）
- DeepSeek-V4.1 + RAG（同底座知识增强基线）
- Single-Agent（同底座、同知识库、去掉多智能体协同）
- 司南礼客（完整系统）

14 项能力：

1. 岗位建模
2. 需求诊断
3. 三类资源
4. 学情画像
5. 路径规划
6. 多智能体协同
7. 交叉校验
8. 证据溯源
9. 风险否决
10. 人工复核
11. 动态反馈
12. 技能沉淀
13. 未见迁移
14. 私有部署

呈现方式：

- 其他模型使用蓝色 `✓` 与红色 `×`。
- 司南礼客所在最后一行整行高亮。
- 最后一行 14 项全部为 `✓`。
- 底部只写：`从“会回答”到“能交付”　全链路能力支持`。

当前页面文字量：约 216 个非空字符，其中汉字约 99 个。参考示例约为 161 个非空字符、102 个汉字。

## 3. 定量分析页

标题：**定量分析 >> 三项硬指标全面达标**

表格规模：5 行模型 × 3 项指标。

模型与占位数据：

| 模型 | 可信性：专业知识幻觉率 ↓ | 适配性：画像资源适配率 | 覆盖性：核心知识点覆盖率 |
|---|---:|---:|---:|
| GPT-6 Astra | 12.6% | 74.2% | 79.8% |
| Qwen3.8-Max + RAG | 11.8% | 79.6% | 83.9% |
| DeepSeek-V4.1 + RAG | 9.7% | 83.8% | 88.5% |
| Single-Agent | 7.9% | 87.6% | 90.8% |
| 司南礼客 | 3.7% | 91.6% | 95.8% |

呈现方式：

- 表头为整行深蓝。
- 每个单元格只放一个百分比。
- 司南礼客整行浅蓝高亮，左侧仅保留一条细金色强调，不使用红色框线。
- 项目名放大但保持主题深蓝，不使用红色；三项结果使用更大字号，奖杯固定列宽对齐。
- 模型名前使用真实图标：OpenAI、Qwen、DeepSeek；Single-Agent 使用智能体图标；司南礼客使用项目图标。
- 底部结论中“核心指标全面领先”使用金色大字，其余说明保持白色。
- 底部只写：`核心指标全面领先　于三大前沿模型与 Single-Agent 基线`。

当前页面文字量：约 220 个非空字符，其中汉字约 71 个。参考示例约为 199 个非空字符、67 个汉字。

## 4. 对照设计说明

对照不是随意挑选模型，而是采用“外部强基线 + 同底座单智能体消融”：

1. `GPT-6 Astra`：检验系统相对 2026 年前沿闭源旗舰是否仍有增益。
2. `Qwen3.8-Max + RAG`：检验系统相对国产前沿模型 + 常规检索增强是否仍有增益。
3. `DeepSeek-V4.1 + RAG`：与完整系统使用同一底座和同一知识库，只保留检索增强，检验只做 RAG 是否足够。
4. `Single-Agent`：同底座、同知识库、同提示词预算，去掉多智能体协同、证据闸门与学习者孪生，检验架构增益。
5. `司南礼客`：完整系统。

表头统一写“对比设置（统一测试集 / 2026-10 版本）”：既说明对比对象不是旧模型，也说明所有对象使用同一测试集，避免被理解为不公平横评。不再连续放三条 DeepSeek 变体，避免视觉上像“同一模型刷三行”。

## 5. 正式替换数据时必须补齐

1. 测试集版本、案例来源和去重规则。
2. 三类 learner profile 的样本分布。
3. 高风险案例、未见场景的构造规则。
4. 模型版本、提示词版本、知识库版本。
5. 人工盲评人数、评分表和一致性。
6. 原始运行日志、评测脚本和失败案例分析。

样本量、指标定义和消融实验放到后续单独页面，不能重新塞回这两页。

## 6. 答辩口径

定性页只说一句：

> 通用模型能回答局部问题，但只有完整系统把岗位任务、个性化资源、证据链、高风险否决和能力沉淀连成一条交付链。

定量页只说一句：

> 在三项赛题硬指标上，司南礼客同时越过门槛，并领先通用模型和单 Agent 基线。
