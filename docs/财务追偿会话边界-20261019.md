# 财务追偿会话边界

更新时间：2026-10-19

## 问题

学员在客户单聊里说明“临时换车费 400 由车队承担”时，系统把财务定责回复也写进了客户单聊，且发言人是笼统的“车队”。这会让客户看到本该属于内部资源的回复，也无法区分不同订单的车队。

## 修正

- 财务定责只在资源对接群或资源方单聊中触发；客户单聊只保留定制师对客户的说明。
- 车辆责任优先落到本单具体的司机联系人，没有司机联系人时使用本单城市级车队联系人。
- 发言人不再直接使用台账字段“车队”，而是使用具体人名，例如“桂林司机·吴师傅”。
- 财务台账仍按供应商类型记录，结算和责任比例不受显示名影响。

## 验证

客户单聊发送“临时换车费 400 由车队承担”后，客户会话不再出现“车队”或本单司机回复，损失保持待处理；在司机单聊发送同一句，定责完成，回复人为本单具体司机。
