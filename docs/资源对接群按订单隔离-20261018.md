# 资源对接群按订单隔离

更新时间：2026-10-18

## 设计口径

资源对接群是定制师接单后，用来整理需求、询问地接 / 酒店 / 车队 / 票务 / 司导档期与价格、统筹本单资源执行的内部协作群。客户不进入该群，客户沟通使用客户群或客户单聊。

## 本次修复

- 资源对接群改为每单一个，不再把所有订单的资源方混在一个账号级大群里；
- 群成员只取该订单已经添加的地接、酒店、车队、票务、导游和司机；
- 客户联系人即使已经添加，也不会进入资源群成员列表；
- 邀请弹窗和邀请接口都拒绝把客户拉进资源群；
- 聊天页打开某个会话时，会按该会话所属订单加载对应的资源群，避免套用别的订单；
- 资源群侧栏不再显示客户名作为群成员或群上下文，订单号仍可点击回到订单详情。

## 涉及位置

- tripcraft/services/supplier_service.py：按订单建群、成员刷新、禁止客户入群；
- tripcraft/services/deliverable_service.py：交付物默认发到本单资源群；
- tripcraft/services/director_service.py：事件找不到目标会话时落到本单资源群；
- tripcraft/api/routers/calls.py：聊天页按当前会话所属订单返回资源群；
- frontend/src/views/practice/ImView.vue：打开会话时同步订单上下文，邀请列表过滤客户；
- tests/test_supplier_service.py：新增订单隔离、客户排除、邀请拦截测试。

## 验证

专项测试 11 项通过；前端类型检查与构建通过。实机聊天页中，周先生订单的资源对接群成员为：我、司机吴师傅、广西地接刘经理、导游周，共 4 位，无客户。

## 资源询价的路由修正

资源询价不是让所有资源方轮流说话，而是按本单真实成员和当前上下文分派：

1. 接单后，平台指派的地接自动进入本单资源群；群内只有我、地接和后续加入的资源联系人。
2. 问酒店或车队时，系统先把这一单对应的可用联系人拉进群，再由这个真实联系人回复。
3. 没点名的短追问沿用上一轮发言的资源方，例如酒店报价后问“大床还是标间”，由酒店继续回答。
4. 同时问酒店、用车、司导等多项，或问司导档期时，由地接按打包口径统一回答；具体司导人选等行前排班后再确定。
5. 学员只是说明“这是客户某某”时，系统提示客户不进入资源群，不让资源方对客户直接说话。
6. 资源方给出具体价格、库存或档期后，这次聊天会登记一条 S4“供应商询价”证据，行前2的资源询价步骤可以直接完成。

事件里的占位名也会替换成这一单真实的地接、酒店、车队或司导联系人，不再出现“XX地接·张经理”这样的假名字。

## 2026-10-19 地接确认后生成城市资源

资源询价顺序固定为：学员先在资源群把城市、日期、酒店/司导/车队/门票和特别要求告诉地接；地接回答价格与档期后，导演 Agent 才把本单本城需要的资源放进可添加联系人。

- 资源池由导演写入订单事实，包含城市、资源类型、日期和原始询问。
- 地接回答前，酒店、车队、导游、司机均不可添加。
- 地接回答后，酒店、车队、导游、司机按城市生成联系人，例如大理酒店、大理车队、大理导游、大理司机。
- 更换城市会重新生成该城市的资源池，旧城市联系人不再用于本单。
- 酒店、车队、导游、司机仍由学员点击添加，不会被自动塞进资源群。
- 票务是独立固定窗口“票务询价”，和资源对接群一样长期存在、无需添加联系人；只回答日期、起点、终点和公共交通方式的班次时间与参考票价。

相关实现：

- tripcraft/services/director_service.py：materialize_resource_pool
- tripcraft/services/supplier_service.py：resource_inquiry_kinds、resource_pool、票务固定窗口
- tripcraft/api/routers/calls.py：按订单返回资源群和票务固定窗口
- frontend/src/views/practice/ImView.vue：资源生成后刷新可添加联系人，票务固定窗口不收成员
- tests/test_supplier_service.py：城市资源池与票务窗口测试

## 2026-10-19 首呼、需求确认与语音输入

首呼结束后自动进入聊天界面，此时本单只开放客户联系人。学员添加客户后自动进入需求确认单；提交需求确认单后回到客户单聊，并把文档发给客户。需求确认单在客户未添加前不能填写或提交。

城市识别不再局限于少量白名单：江苏的宿迁、常州、无锡、苏州，云南的大理、丽江、香格里拉等城市名都能切换到对应城市。换城后旧城市酒店、车队、司导联系人不再参与本单，地接会重新确认本城资源并生成新城市联系人。

聊天输入区增加语音输入按钮。录音通过现有 Qwen 语音通道在后端转写，识别结果填入输入框，由学员确认后发送；不会自动发送。切换会话或离开页面会停止录音。
