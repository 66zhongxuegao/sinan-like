# 游客证件称谓与首呼规则

核对日期：2026-10-17。适用场景为游客来中国内地/大陆旅行，以及内地游客在内地/大陆旅游。

| 游客身份 | 提示词使用的名称与适用条件 |
| --- | --- |
| 中国籍香港、澳门居民来内地 | 有效《港澳居民来往内地通行证》，俗称“回乡证”。 |
| 非中国籍港澳永久性居民来内地 | 已获签发的有效《港澳居民来往内地通行证（非中国籍）》可用于短期旅游等；其他情形按本人外国护照及适用的中国签证、免签或其他入境许可处理。 |
| 台湾居民来大陆 | 有效《台湾居民来往大陆通行证》，简称“台胞证”。 |
| 外国游客 | 有效护照或其他国际旅行证件，及适用的有效中国签证或其他入境许可；旅游通常对应 L 字签证。符合当期免签条件、持有效外国人居留证件等情形可免办签证。 |
| 旅居海外的中国公民回国 | 有效《中华人民共和国护照》，或符合签发条件的有效《中华人民共和国旅行证》等中国旅行证件；保持中国国籍者回国不套用外国人办理中国签证的设定。 |
| 内地游客在内地/大陆旅游 | 不主动提及证件、签证、出入境办理；提示词不再向客户注入证件类型或将证件列为待确认需求。 |

“往来港澳通行证”和相应签注用于内地居民赴香港、澳门；港澳居民来内地使用的通行证名称与旅行方向有区别。不能将“港澳通行证”泛化为港澳游客来内地的证件名称。

## 实际写入提示词的表达边界

- 客源地表示来源或居住地，不据此断定国籍、永久居民身份、持证状态、签证办理状态或免签资格。
- 默认提供的证件类型只作称谓参考。资料未说明时，不说“我已经办好”“全家都有”或“肯定免签”。
- 首呼先自然表达旅行意向。仅在对方问到、本人有明确疑问或行程确有需要时谈证件，不罗列全部类别，不反复引回证件话题。
- 明确区分国籍、来源地、国内旅行类型。可选订单字段 `citizenship` 表示明确公民身份，`traveler_type` 可标记 `domestic`、`inbound`、`overseas_chinese`；没有这些信息时不自行补全。
- 不固化免签国家名单、停留期限、办理材料或统一的“护照/证件需剩余六个月”要求。这些项目按出行时官方政策及实际行程核验。

## 代码覆盖

- `tripcraft/contracts/entry_documents.py`：共用名称、国内识别、类型规范化和按身份适用的提示词规则。
- 文字首呼、语音首呼和客户 IM 共用客户人设与事实渲染，采用同一套证件规则。
- 语音的备用资料入口也处理顶层 `docs/documents`，并过滤国内订单证件字段。
- 通话及订单详情中的公开证件资料也采用共用规范化结果，国内游客对应字段留空。
- 默认偏好与隐藏诉求改为旅行节奏、住宿、预算和舒适度，取消统一的入境手续焦虑。
- 派单与旧演示候选池不再按来源国家写死“需办理签证/免签入境”。旧订单中这种无条件类型描述在组装模型上下文时改成待核验线索；不修改历史数据库。
- 已有入境派单市场范围保持原样，国内游客规则用于明确标记为国内或客源地为内地的订单。
