# 三类能力雷达与历史记录

2026-10-17

## 使用方式

- 学情画像页的雷达支持三个独立开关：橙色实战能力、蓝色学习能力、亮灰色初始能力。
- 左侧“当前能力”显示最新能力；带日期时间的按钮显示该次保存的记录。
- 点击“更新画像”后，报告和三类雷达数值一起保存，记录显示精确到秒的保存时间，并自动选中新记录。
- 切换历史记录不会更新或覆盖该记录；重新登录后仍可查看。
- 未评估维度显示为空。有部分维度记录时，只绘制已知点和相邻已知点之间的连线；不把缺失维度画成零分。

## 数据口径

初始能力来自 `profile_baseline`，旧账号可读取实际保存的初始报告。学习能力来自学习地图训练写入的 `ability.teach`；初始测评初始化的 teach 值有独立来源标识，不会直接变成蓝色训练成绩。实战能力来自评分流程正式写入的 `ability.real_v`，保留原有覆盖度、校准与复核规则。

维度值为该来源已评估技能点的掌握度均值；未评估技能点不按零分计入。零分如果已正式评估，会作为有效数值保留。页面顶部的当前训练掌握度使用相同来源口径。

旧账号升级时，学习来源按已有做题记录识别，已有非零实战能力保留。已有初始记录可在历史列表中查看；旧版未保存的训练快照不倒推补造。从本次改版开始，每次画像更新均保存完整快照。

## 实现

- `ability` 增加学习、实战各自的来源和更新时间字段；应用下次启动时自动补齐。
- `profile_snapshot` 保存当次完整雷达和报告 JSON，记录按账号隔离。
- `POST /profiles/{id}/refresh` 保存报告、快照并返回新记录。
- `GET /profiles/{id}/radar/history` 列出本人的保存时间。
- `GET /profiles/{id}/radar/history/{snapshot_id}` 读取当时的快照；其他账号无权访问。
- 初始测评完成后也自动保存第一条记录。标准案例明确选择重置学习与画像时，会同步清理该账号的基线与快照。
