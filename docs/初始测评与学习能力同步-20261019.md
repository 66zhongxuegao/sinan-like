# 初始测评与学习能力同步

更新时间：2026-10-19

## 问题

初始测评把能力写入 ability.teach，来源标记为 initial；学习地图直接读取 teach，因此能看到分数。画像雷达的“学习能力”层只统计来源为 learning 的记录，把 initial 当成继承值，所以画像页显示未评估或与学习地图不一致。

## 修正

画像雷达现在把 initial 和 learning 两种教学来源都纳入学习能力层：

- 初始测评分数作为学习能力起点；
- 后续学习地图答题继续以 learning 来源更新同一指标；
- 初始能力层仍读取 profile_baseline，不受影响；
- 画像页、学习地图和技能点详情使用同一份 teach 数值。

## 验证

测试账号 7837837 的画像学习能力加权值为 73.8，学习地图 overall.teach 同为 73.8；C1–C8 八个维度的数值逐项一致。
