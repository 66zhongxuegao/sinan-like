# 实战完成提示与画像覆盖解耦

2026-10-17

## 评分与画像

覆盖校验继续统计考核目标、已覆盖数量、覆盖率和未覆盖原因，用于评分复盘参考。覆盖率低于 80% 不再阻止已评估技能点写回画像。评分仍按已有证据生成，保留校准和低置信度复核规则。

订单复盘评分现在是画像的自动更新时间点：只要本次有分数正式写回，评分接口会立即重算并保存一份画像快照，前端提示“画像已自动更新”；画像页的“手动刷新画像”保留为兜底。全部转人工复核、校准未通过或本次没有正式写回时，不会伪造画像更新。

评分完成后会弹出复盘框：展示本单平均分、评出技能点、写回数量、待复核数量；逐点列出评分前后能力值、M 档和变化；并预览下一单整单难度、3 个主考点、7 个难度旋钮、首呼时限与画像依据。画像未正式写回时，框内明确提示“本次未写回”，不展示虚假变化。

评分复盘页去掉覆盖率与画像写入关联的文案，以及“一单只按画像抽……四类状态”整段说明。覆盖率区域改为“覆盖率供复盘参考，不影响画像展示”。

学习或实战已经涉及的维度使用相应训练结果；尚未涉及的维度沿用本人初始画像。在两份行后文件均已提交、尚未生成评分时，实战雷达也可展示初始值。继承值标记 `inherited=true`、`source=initial`、`assessed_points=0`，圆点提示“沿用初始画像”；不会向能力表写入虚构实战评分。本人尚无初始测评的维度继续显示未评估。

兼容历史“评分已入库、能力尚未写回”的情况：雷达直接读取本人有证据、状态已入库的评分记录，使用最新有效结果；待复核、驳回、无证据或超范围分数不采纳。只读展示不会改写能力表。更新画像的定性报告与雷达使用同一组维度结果。

## 完成条件与全屏提示

统一完成条件定义为“地接结算核对单”和“回访与复盘记录”两份文件均成功提交，顺序不限。草稿、其他文件、失败提交不计完成。完成判定独立于旧平台阶段门槛及覆盖率。

交付物列表与提交回执均返回 `training_completion`：完成状态、完成时间、两份文件状态及本单评分复盘路由。第二份行后文件成功提交后，全屏提示：

> 恭喜您完成了一次实战训练
>
> 点击跳转至评分复盘

按钮为“跳转至评分复盘”，进入当前订单的评分复盘。刷新已完成文件或重复读取回执不重复弹出。切换订单时清空弹窗状态。弹窗支持键盘焦点和滚动锁定，离开时恢复。

## 验证

离线内存库覆盖两种提交顺序、仅行后文件即可完成、失败提交与草稿不计完成、重复提交及账号隔离。另验证低覆盖率的合格评分仍写回，未涉及维度继承初始值，真实零分保留，历史初始快照不会混入新训练值。

前端通过类型检查与生产构建。使用独立组件预览检查全屏布局、指定文案与按钮事件，不操作真实订单。预览截图保存在 `.deploy-cache/practice-completion-preview.png`。
